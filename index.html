01 — Verdict

一次精准的牌照套利

认证行业的核心资产是牌照，不是能力。ZeroCarbon Verify 做的事很清楚：把需要 ISO/IEC 17065 牌照的签字权，外包给已经持牌的伙伴；把不需要牌照的计量、分级、哈希、注册表，全部留在自己手里。

结果是一个位置极好的中间层 —— 它让持证方的签名变得便宜、难以挑战，同时自己永远不承担"下结论"的法律责任。买家拿到的不是一张证书，是一条可以在浏览器里重算的证据链。

签字可以被租用。
证据层不能。 — 网站自己的两轨计划，原话的意思是：the signing layer can be borrowed; the evidence layer cannot.
最锋利的一刀

计量单位从"企业"降到"批次"

EUDR、CBAM、海关、提单，全部作用于货物，不作用于法人。SGS / BV / TÜV 还在按企业出 Scope 3 报告。它直接对准货物流 —— 这不是改良，是换了坐标系。

最脆弱的一刀

¥40 一次签发，没有人会签

500 批/年 = 500 次签发责任，持证方总共只拿 ¥20,000。任何持牌机构不会用 ¥40 承担一次 17065 责任。这个数字撑不起它自己的产品结构。

02 — The stack

四层价值栈：被验证方、付款方、受益方，三者必须不是同一个人

为什么不向农场收费

向被验证方收费，它立刻变成"买结论"，证据失效。免费是结构性必要，不是慷慨。

为什么不让签字费浮动

一旦签字费和结论质量挂钩，结论就可以被定价腐败。¥40 固定的真正价值是抗腐设计，不是价格。

为什么免费层要故意做残

grade U，不可引用，无 statement reference。免费用户永远拿不到"可被依赖"的东西 —— 反 freemium 自我蚕食。

04 — Surprises

让我惊讶的七件事

不是因为它们新，而是因为它们在一个靠模糊赚钱的行业里，选择了相反的方向。

  1. 把"拒绝"做成了产品

    出不了结论照样按日费率收工时费，且"不给结论不收结论费"。拒绝有语义、有价格、有书面理由。多数认证机构做不到说"不"。

  2. 公开价目表当竞争武器

    认证业价格从不公开。它把 A ¥80 / B ¥60 / C ¥40 和固定 ¥40 签名分成全挂出来，等于提前杀死"我多付的钱去哪了"这个问题。

  3. 免费层故意做残

    grade U、不可引用、2 批/年上限。免费版拿不到"可被依赖"的东西，所以永远不会替代付费层。

  4. 主动自曝，把合规负债转成营销资产

    承认旧价 ¥15,000 是错的、承认 20 条记录全是模拟、承认无牌照无伙伴。这是反常识的：这个行业靠模糊赚钱。

  5. 结构性放弃咨询收入

    碳服务市场最大的一块被组织架构焊死。SGS / BV 两头吃咨询 + 验证长期被诟病，它直接自断后路。

  6. 转换成本不是合同，是证据链历史

    "Nothing is reset"。无排他条款，但换供应商等于历史归零。比合同锁更狠，且不损害客户利益。

  7. 它把"诚实"当成了唯一无法被复制的资产

    方法可以抄，价格可以跟，哈希可以重写。但一个敢在首页写"未认证、无伙伴、20 条全是模拟"的机构，抄起来需要付出品牌代价。

05 — Standing

现状不是"一家公司"，
是一份很硬的方法论文档

一份方法论文档 + 一套很聪明的定价结构 + 20 条模拟记录 + 0 个签名伙伴。商业模式的设计成熟度，比执行领先约 18 个月。

真正的瓶颈不是模型，是第一张被第三方持证机构签字的真标签。在它出现之前，上面所有精妙结构都还只是自我声明。
