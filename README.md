# carbonverify.workbuddy

独立第三方拆解：**carbonverify.cn**（ZeroCarbon Verify）的商业模式与收入模型。

与该公司无关联、未获授权、不代表其观点。全部结论基于 2026-11-09 公开页面的重新核算。

## 页面

| 路径 | 内容 |
|---|---|
| `index.html` | 判决、四层价值栈、七个惊讶点 |
| `model.html` | 商业模型解剖、单位经济性推导、盈亏平衡 |
| `revenue.html` | 六条收入引擎排序 + 单农场经济性交互测算器 |
| `bugs.html` | 三处硬伤（严重度矩阵）与修法 |
| `rebuild.html` | 我的六条业务线、八季度现金时序、90 天计划 |
| `method.html` | 方法、局限、来源、免责 |

## 技术

纯静态，无构建步骤。`assets/css/site.css` + `assets/js/site.js`。Inter / IBM Plex Mono 通过 Google Fonts 加载。

## 本地预览

```bash
python -m http.server 8000
```
