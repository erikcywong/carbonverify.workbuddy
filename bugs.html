02 — Fatal

唯一一张真实标签，来自自己的生态

网站宣称 "0 equity held in the parties we verify"（不对被验证方持股）。但注册表里那张唯一的 live label —— CJ-CN-2026-0712-63E7，0.1951 kgCO₂e/plantlet，grade B —— 来自 coffeejev.space，而方法编号本身就是 CJV-MTH-1.0。CJV 是同一个人。

为什么这一条是致命的

独立性的关键在于"声明的形式"还是"事实的结构"？在认证行业，答案永远是后者。一家验证机构的第一张标签，比其后一百张都重要 —— 它定义了这家机构在压力下会怎么选择。

如果第一张标签来自创始人的另一个项目：

  • 实际作用：它证明了管线能跑通
  • 象征作用：它证明不了任何独立性

"0 equity" 是一句关于股权的陈述，不是关于控制权、薪酬、共同创始人、共同供应商的陈述。用一条窄口径声明去覆盖一个宽口径风险，是 ESG 行业最典型的手法 —— 由一家把"反 greenwashing"当使命的机构来做，代价更高。

修法 · 三条，按成本排序

先止血，再补结构

1 · 三十天内引入两到三张外部标签。任何愿意免费试的农场、任何一家出口商。不必好看，必须来自无关第三方。

2 · 把口径改准。不要说 "0 equity"，说 "no shareholding, no commission, and full disclosure of founder's other interests" —— 并披露咖啡平台的关系。

3 · 长期。把平台股权放进盲信托，或干脆把验证机构交给一个不含创始人的董事会。这条会痛，但它是唯一能让"独立"从形容词变成名词的办法。

03 — Hash

用 FNV-1a 说"不可篡改"，是技术上站不住的

全站的核心承诺是：任何人可以在浏览器里重算哈希，所以记录不能被事后修改。这个思路对，选错了函数。

问题

FNV-1a 是 32/64 位非密码学哈希。它的设计目标是快速散列，不是抗碰撞。这意味着：

  • 构造两条内容不同、哈希相同的记录，成本极低
  • 有写权限的人可以重造整条链，且链自洽
  • 外人重算得到"一致"，因此看不出篡改

所以它提供的是完整性校验（防手滑、防传输损坏），不是不可篡改性（防对手）。网站把它描述成后者，是过度承诺。而这恰好是一份要拿去给采购部和法务部看的文件。

修法

把哈希换成 SHA-256，并把每日根锚定到公共时间戳。成本每条不到一分钱，还多出一个可卖的产品。

// 现在的做法：链自洽，但可被重造 hash = fnv1a(prev_hash + payload) // 应该的做法：密码学承诺 + 外部时间锚 h = sha256(canonical(payload)) link = sha256(prev_hash || h) root = merkle_root(today_batch) // 每日一次，把 root 提交到 OpenTimestamps ots stamp root → bitcoin block height

这样"不可篡改"就不再依赖网站自己的服务器：要篡改，就得同时篡改一条公共链的历史。同时这一步天然可以按"锚定服务"收费 —— 见 重建方案 第 2 条。

04 — Numbers

三组数字，在同一个站上互相打脸

项目A 处说法B 处说法差异
注册表记录数 首页：20 条参考记录 注册表页正文：100 条中 1 条 live、99 条模拟 5×
EUDR 集装箱包价格 首页 / 专页：¥3,000–8,000 / 柜 model 页：¥2,000 / 柜 −33% ~ −75%
典型批次量 500 批 / 场 / 年（"typical"） 免费层上限：2 批 / 年 256×

第三组不算矛盾 —— 免费层本来就是故意做残的。但它和"500 批/年 typical"并列出现在同一份材料里，会让读者对"typical"这个词产生合理怀疑：这是一个真实的中位数，还是一个为了让单位经济性好看的假设？

在一个把"透明"当作唯一差异化壁垒的机构里，数字不一致的代价比在别处高十倍。因为它的整个说服链条是"你不需要相信我，你可以自己算"。一旦别人算出两个不同的数，这条链就断了 —— 而断点不在数据上，在可信度上。

修法很简单：单一数据源生成所有页面。注册表条数、单价、典型批次量各定义一个常量，页面渲染时读取。一天的工作量，换回整个叙事的一致性。

05 — Also

三件不致命但削弱定位的事

01 · 品牌

ZeroCarbon 卖的是 Verify

名字承诺"零碳"，产品交付"验证"。第一个词是它明确反对的东西（不做 offset、不做 credit）。建议只保留 Verify，或改成能承载"证据"语义的词。

02 · 市场

CNAS 不申请是对的，但要写清

大陆碳核查需备案资质。它明确不申请，等于把 TAM 限定为出口导向供应商（EUDR / CBAM 客户）。这是聪明的楔子，但必须写在定价页上，否则大陆客户会误认。

03 · 阶段

它还不是公司，是文档

一份方法论 + 20 条模拟 + 0 个签名伙伴。用"公司"的语言描述"项目"的阶段，会在第一次尽调里全部退回。承认"pre-revenue"反而更快。
